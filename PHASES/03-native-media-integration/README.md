# Phase 03 Task Index

This folder breaks native media integration into buildable tasks.

## Task Order
1. Media gateway boundary
2. Command routing
3. Metadata and artwork
4. Empty states and fallbacks
5. Verification and quality

## Task Rules
- Keep platform APIs behind the gateway boundary.
- Do not fabricate playback state or metadata.
- Keep UI code out of the native-media layer.
- Make each task independently reviewable.
