# SpotiFloat

SpotiFloat is a beautiful, ultra-sleek floating Spotify widget for Windows that sits elegantly on your desktop (or taskbar) and gives you instant, tactile control over your music. 

## Features
- **Micro-Interactions**: Apple-like bounce physics on all buttons.
- **Dynamic Theming**: Hot-swap between Dark, Light, and a frosted Glass Morphism theme!
- **Always on Top**: Keeps the widget above all other windows (can be toggled off in settings).
- **Auto-Hide on Fullscreen**: Automatically vanishes when you watch YouTube or play games, so it never gets in the way.
- **Portable or Installed**: Available as a completely standalone executable, or as a standard Windows installation.

## How to Use
1. **Launch**: Simply run the `SpotiFloat.exe` (or launch from Start Menu if you installed it).
2. **Move**: Click and drag the widget anywhere on your screen.
3. **Settings**: Right-click the player or right-click the system tray icon to open the Settings menu.
4. **Theme**: Open Settings and use the dropdown to switch themes instantly.

## Uninstallation
- **If you used the Setup Installer**: Go to Windows Settings -> Add or Remove Programs, find "SpotiFloat", and click Uninstall.
- **If you use the Portable EXE**: Open the widget Settings and click the red **Uninstall & Remove Data** button. This will wipe your AppData folder and registry keys, and immediately close the player. You can then delete the `.exe` file safely.
