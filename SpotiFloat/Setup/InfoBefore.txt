Welcome to SpotiFloat

SpotiFloat is a floating Windows music controller with Bar, Square and Disk layouts.
It reads supported desktop music apps through Windows media sessions. Supported
sources are Spotify, Apple Music, Amazon Music, Deezer and TIDAL. Browser media
is intentionally ignored.

Getting started:
1. Open a supported music app and play a track.
2. Drag the widget to position it.
3. Right-click the widget or its tray icon to open Settings or Exit.
4. In Settings, choose the layout, Dark/Light/Glass theme, album-colouring mode
   and size (10-300%). Changes save automatically.

Visualization requires Windows build 20348 or later and a supported active audio
process. Closing Settings leaves the widget running; use Exit to close the app.
