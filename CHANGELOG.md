# Changelog

## 1.2.0 — 2026-10-21

- Shared Bar, Square and Disk layouts with Windows media-session playback controls.
- Desktop source allowlist for Spotify, Apple Music, Amazon Music, Deezer and TIDAL; browser sources excluded.
- Process-specific audio capture and analysis for Square/Disk visualization.
- Dark, Light and Glass themes with independent Off/Title/Accents/Full album colouring.
- Adaptive Full-mode Bar button surfaces and readable icon colours.
- Compact native settings panel, accessible controls, 10-300% sizing, right-click Settings/Exit and installed-copy uninstall lookup.
- Current-project documentation, architecture diagrams, MIT licence and contribution/security guidance.
- Blue SF branding, a multi-resolution app icon and monochrome tray icons for light/dark taskbars.
- Self-contained Windows x64 installer with per-user registration, Start menu shortcut, Windows Settings/Control Panel removal, and bundled licence notices.

This is a public development release. Detailed investigations, open issues and acceptance statuses are retained in [the maintenance history](docs/maintenance/fixes.md). Older releases do not include all changes listed here.
